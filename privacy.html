Privacy policy

SlideSearch · last updated 12 November 2026

Who uses it

SlideSearch is a personal tool that runs on its user's own computer. There is no SlideSearch server and no developer account; nothing is collected by or sent to the developer.

Google user data

  • Permission used: https://www.googleapis.com/auth/drive.file only. SlideSearch can access only the "SlideSearch" folder and the files it creates there. It cannot see, read, change or delete any other file in the user's Google Drive.
  • What it does with it: it uploads its own search index and PDF copies of the user's study slides to that folder, and downloads them on the user's other computers.
  • Where the sign-in is kept: the Google sign-in token is stored only on the user's own computer, in the SlideSearch folder. The user can remove access at any time in the app ("연결 해제") or at myaccount.google.com/permissions.
  • Sharing: Google user data is not shared with, sold to, or transferred to anyone, and is not used for advertising or to train AI models.

Other services

If the user enables it with their own API key, SlideSearch sends slide images and text to Anthropic's Claude API to read text in images and to write study summaries and flashcards. These requests go directly from the user's computer to Anthropic under the user's own account, only when the user runs those features. On a computer that downloaded the index from Google Drive, the slide text used for a requested summary comes from that downloaded index; it is sent only for that user-requested feature and for no other purpose.
