SlideSearch

A personal desktop tool for searching radiology board-exam study slides.

SlideSearch runs on the user's own Windows computer. It indexes the user's own PowerPoint and PDF study decks so that a keyword or a screenshot of a problem finds the relevant slides, and it can write a short study summary and Anki flashcards from them.

Google Drive

Optionally, SlideSearch copies its search index to the user's own Google Drive so the same index can be used on the user's other computers. It uses only the drive.file permission: it can access only the "SlideSearch" folder and the files it creates there, and cannot see any other file in the user's Drive.
